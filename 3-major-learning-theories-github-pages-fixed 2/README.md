# The 3 Major Learning Theories

Interactive e-learning course created with Articulate Rise 360.

## Portfolio version

This repository contains a portfolio-hosting version of the original Rise/SCORM export. The launch guard in the exported `scormcontent/index.html` has been adjusted so the course can load outside an LMS when hosted as a static website such as GitHub Pages.

**Note:** GitHub Pages is not an LMS, so SCORM tracking/completion/reporting is not available. This repository is intended for portfolio demonstration only.

## View the course

After GitHub Pages is enabled, open:

`https://YOUR-USERNAME.github.io/3-major-learning-theories/`

## Project

**Title:** The 3 Major Learning Theories: Behaviorism, Constructivism, & Cognitivism

**Tool:** Articulate Rise 360

**Focus:** Learning theory, instructional design, interactive e-learning, cognitive load, accessibility, and learner engagement.
